# Doggy AI — веб-клиент

Чат-интерфейс для Doggy AI: React + Tailwind CSS + Phosphor Icons.
Ориентир по структуре — Claude (боковая панель, лента сообщений, композер снизу),
но с собственной визуальной идентичностью.

## Концепт-дизайн

**Идея.** Doggy — дружелюбный, но компетентный ИИ-ассистент. Не мультяшный щенок,
а «умный пёс, который всегда рядом»: тёплый, но собранный интерфейс, в котором
«собачья» тема прочитывается через детали (иконка лапы как индикатор набора,
скругления, тон текста), а не через иллюстрации.

**Палитра** (не крем+терракота и не чёрный+неон — сознательно уходим от этого):

| Токен | Светлая тема | Тёмная тема | Роль |
|---|---|---|---|
| `--bg` | `#F5F6F2` (холодный бумажный) | `#1C1E19` (тёплый уголь) | фон приложения |
| `--bg-sidebar` | `#EDEEE7` | `#17180F`→`#171812` | боковая панель |
| `--bg-elevated` | `#FFFFFF` | `#24261F` | карточки, модалки, композер |
| `--border` | `#DEDFD5` | `#34362C` | границы, разделители |
| `--text-primary` | `#23241F` | `#F1F1EA` | основной текст |
| `--text-secondary` | `#6B6D61` | `#A8AA9C` | вторичный текст |
| `--accent` (Marigold) | `#C97A2B` | `#E0954A` | основной акцент — CTA, бренд, режим Search |
| `--moss` | `#56705A` | `#7FA085` | вторичный акцент — режим Agent |
| `--danger` | `#B24B32` | `#E07354` | ошибки |

Один акцентный цвет (marigold) — для первичных действий и бренда. Мох — только
для состояния режима Agent. Никаких градиентов, только плоские заливки и
тонкие 1px границы; тень — только у всплывающих поверхностей (модалки, поповеры).

**Типографика.** Два семейства, ясно различимые:
- **Fraunces** (вариативный serif с тёплыми, «рукописными» засечками) — для
  логотипа и заголовка пустого состояния. Используется как акцентный элемент,
  не как нейтральный текст.
- **Inter** — для всего интерфейса: сообщения, кнопки, панель.

**Layout.** Классические три зоны: боковая панель (280px, схлопывается в
выезжающую панель на мобильных), лента диалога по центру (max-width 720px),
закреплённый композер снизу с сегментированным переключателем Search/Agent.

**Принципы:**
1. Один акцент по умолчанию (marigold), мох — только как маркер режима Agent.
2. Без градиентов; скругления осмысленно разные по иерархии (пузыри сообщений
   круглее панелей, панели круглее самой рамки окна).
3. Анимации точечные и привязаны к действию: раскрытие пустого состояния при
   загрузке, появление сообщений, скользящий индикатор режима, пульсация
   «лап» во время набора ответа — никаких декоративных hover-эффектов на
   каждой карточке.
4. «Собачья» тема — через функциональные детали (PawPrint как индикатор
   набора/логотип), не через иллюстрации щенков.

## Установка

```bash
npm install
npm install @phosphor-icons/react
npm run dev
```

Проект ожидает Tailwind CSS (`darkMode: 'class'`) и шрифты Fraunces + Inter,
подключённые в `index.html` (см. `index.html`).

## Иконка сайта

`public/` содержит фавикон в нескольких размерах (favicon-32, icon-192,
icon-512, apple-touch-icon) и подключён в `index.html`. Исходник уже был с
прозрачным фоном за пределами скруглённого квадрата — просто обрезан и
приведён к нужным размерам.

В корне проекта также лежит `doggy-ai-icon.svg` (копия — в `public/`, подключена
как favicon) — это уже настоящий трассированный вектор, не PNG в обёртке.
Собран собственным пайплайном (потрейс-бинарника в среде сборки не было):
цвета квантованы в ~16 кластеров (k-means), по каждому цвету найдены контуры
(OpenCV), упрощены и переведены в гладкие кубические Безье через
Catmull-Rom. Стиль получается плоским/постеризованным — оттенки фона легли
полосами вместо гладкого градиента, это ожидаемое следствие трассировки
многоцветной картинки с растровыми полутонами. Все линии — настоящие
векторные path, масштабируются без потери качества.

## Подключение к бэкенду агента

Сайт общается с реальным бэкендом (`server_core.py`, папка `backend/` рядом
с проектом). Адрес задаётся через `VITE_API_BASE_URL` (см. `.env.example`),
по умолчанию `http://localhost:8000`.

| Что на сайте | Как работает |
|---|---|
| Чат (Research) | `POST /ask_stream`: этапы поиска, затем текст. Ответ опирается на проиндексированные txt/md/pdf/docx |
| Режим Agent | тот же вызов с `execute_code=1`: один блок ```python выполняется в песочнице |
| Библиотека | `POST/GET/DELETE /library` — реальный индекс и граф понятий |
| Экспорт | контекстное меню ответа: Markdown локально, DOCX и PDF через `POST /export` |
| Скилл | локальная доп. инструкция, уходит в `task_prompt` |
| Индикатор «офлайн» | `GET /health` |

Веб-поиск, генерация картинок, тарифы и вход через Telegram у study-agent нет — кнопки не притворяются рабочими.

## Структура


```
src/
  App.jsx                  — корневой компонент, состояние приложения
  components/
    Sidebar.jsx             — история чатов, режим, план, Telegram
    ChatArea.jsx             — пустое состояние + лента сообщений
    MessageBubble.jsx        — сообщение пользователя/ассистента
    Composer.jsx             — поле ввода, переключатель Search/Agent
    TopBar.jsx               — мобильный хедер, переключатель темы
    TelegramModal.jsx        — привязка Telegram-аккаунта
    PlansModal.jsx            — тарифы Free / Base / Pro
  styles/
    theme.css                — CSS-переменные светлой/тёмной темы
  index.css                  — Tailwind + базовые стили
tailwind.config.js
index.html
```
